### Deploy SVG Routing Pipeline

Converts a raster PNG into a routed, merged SVG skeleton and serves a demo viewer.

1. **PNG → Skeleton PNG**

```bash
python .\skeletonize.py .\test.png test
```

Output → `test_sk.png`, `test_overlay.png`

2. **PNG → Base SVG**

```bash
docker run --rm -v ${PWD}:/work potracer "magick test.png -threshold 99% test.pbm && potrace test.pbm -s -o test.svg"
```

Output → `test.svg`

3. **Skeleton PNG → Skeleton SVG**

```bash
docker run --rm -v "$(pwd):/app" autotrace /app/test_sk.png -centerline -output-file /app/test_sk.svg
```

Output → `test_sk.svg`

4. **Skeleton SVG → Linearized Skeleton SVG**

```bash
python linearize.py test_sk.svg test_sklin.svg
```

Output → `test_sklin.svg`

5. **Merge SVGs**

```bash
./merge.sh
```

Output → `merged.svg`

6. **Run Demo Server**

```bash
npx serve .
```

Open in Browser →
[http://localhost:3000/index.html](http://localhost:3000/index.html)

Notes:

* Docker images `autotrace` and `potracer` must already exist.
* `merged.svg` is generated by `merge.sh`.
* Must use HTTP server (not file://) or fetch() will fail.
