Deploy SVG Routing Pipeline

1. Generate Skeleton PNG
   python skeletonize.py input.png test

2. Convert Skeleton PNG → SVG (AutoTrace)
   docker run --rm -v "${PWD}:/app" autotrace test_sk.png -centerline -output-file test_sk.svg

3. Linearize + Snap + Simplify
   python linearize.py test_sk.svg test_sklin.svg

4. Convert Base PNG → SVG (Potrace)
   docker run --rm -v "${PWD}:/work" potracer sh -c "magick input.png -threshold 99% test.pbm && potrace test.pbm -s -o test.svg"

5. Merge Base + Skeleton SVG
   sh merge.sh

6. Run Demo Server
   npx serve .

Open in Browser
[http://localhost:3000/index.html](http://localhost:3000/index.html)

Notes:

* Docker images `autotrace` and `potracer` must already exist.
* `merged.svg` is generated by `merge.sh`.
* Must use HTTP server (not file://) or fetch() will fail.
